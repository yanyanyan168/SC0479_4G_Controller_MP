# SC0479 4G智能控制器微信小程序 V2.0

## 1. 工程说明

这是完整的 uni-app / Vue 3 小程序工程，不是覆盖补丁。

本版在现有已联通工程基础上重构，按照以下文档实现：

- 《4G智能控制器内部开发需求说明——小程序端》
- 《4G智能控制器MQTT JSON通信协议书》

## 2. 打开和运行

1. 用 HBuilderX 打开本工程目录。
2. 确认 `manifest.json` 中微信小程序 AppID 正确。
3. 选择“运行到微信开发者工具”。
4. 在微信公众平台配置 MQTT WebSocket 对应的 socket 合法域名。
5. 设备正式联调时，将 MQTT 地址改为项目正式服务器地址。

本工程使用原生 WebSocket MQTT 3.1.1 客户端，不需要执行 npm 安装命令。

## 3. 主要功能

- 深色“设备控制台”首页。
- 扫码或手动输入设备 ID 绑定设备。
- 一个 MQTT 长连接同时订阅多台设备。
- 手动控制网口 1、网口 2、光猫。
- 全部开启、全部关闭。
- 单通道和全部恢复自动。
- 每通道仅一个定时任务。
- 每任务 1～3 个时间段，精度 1 分钟，不允许跨天。
- 一周七天选择，以及每天、工作日、周末快捷选择。
- 全局间歇断网参数，仅作用于网口 1、网口 2。
- 离线设备禁止控制。
- ACK 按 `dev_id + seq + ack_cmd` 严格匹配。
- MQTT 断开后自动重连。

## 4. 设备绑定

正式设备ID格式：

```text
GW4G_000000001
```

用户手动添加时只输入：

```text
000000001
```

扫码内容也以9位数字为主。小程序会自动补充 `GW4G_` 前缀。

为兼容已经制作的测试二维码，程序仍可识别完整设备ID和早期JSON二维码。

小程序首次运行默认不创建任何设备。用户扫码或手工添加后，设备按添加顺序编号。

## 5. 设备列表显示

- 在线设备置顶，显示完整控制卡片。
- 离线设备不显示完整控制卡片。
- 离线设备在列表下方简洁显示：`GW4G_000000001 已经离线`。
- 设备标题中的“设备”文字已删除，由设备图标表达，旁边只显示添加顺序编号。

## 6. 用户模式与调试模式

模式入口位于设置页底部，默认低调显示。

调试模式可查看：

- MQTT WebSocket 地址
- Topic 根路径
- 收发日志
- 模拟状态和模拟 ACK

正式用户界面不会显示 Topic、ACK、RTC、AT 命令等工程信息。
